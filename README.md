# Mundo das Letras

Projeto de alfabetização acessível feito com HTML, CSS e JavaScript puro.

## Como executar
1. Extraia a pasta/arquivo ZIP.
2. Abra `index.html` no navegador (Chrome, Edge ou Firefox).
3. Para melhor compatibilidade com leitura em voz alta, permita o uso de áudio no navegador.

## Funcionalidades
- Navegação entre Início, Alfabeto, Sílabas, Palavras, Frases, Jogos e Progresso.
- Alfabeto interativo com exemplos, imagens emoji e leitura em voz alta.
- Atividade de formação de sílabas.
- Reconhecimento de palavras por figuras.
- Organização de palavras para formar frases.
- Jogo de caça à letra.
- Jogo da memória com pares.
- Estrelas, conquistas e progresso salvos no `localStorage` do navegador.
- Opções de acessibilidade: texto maior, alto contraste, reduzir animações e leitura em voz alta.
- Layout responsivo para celular, tablet e computador.

## Observações importantes
Este é um protótipo educacional inicial. Pessoas com síndrome de Down têm perfis e ritmos de aprendizagem diferentes; adapte palavras, imagens, tempo, nível de ajuda e atividades à pessoa que estiver usando. O sistema não substitui avaliação ou acompanhamento pedagógico individualizado.
